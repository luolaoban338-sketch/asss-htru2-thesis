# R09 特征选择基线比较方案

协议草案 1.0　｜　2026 年 11 月 3 日　｜　HTRU2 开发比较

用相同的分层随机半样本、都从八个变量中选四个，并拟合相同的最终分类器时，ASSS111 与 L1 系数排序的外层 F1 相差多少？主比较保留全部五折及差值方向。L1 在先前全行比较中是有竞争力的参照，其训练步骤也可以逐项计数。

## 如何衔接旧方法

若取得能关联报告版本的脚本、配置或日志，先核对原数据版本、标签、列字典、划分、τ、效用及每一步选列轨迹，将入选列与原始运行记录逐项比对，再按报告精度核对表 3、4 的预测指标和平均贡献。只有流程与报告结果均有对应证据，才把这一步记作历史复现。移植到 HTRU2 后另外命名、另报测试结果。

若关键字段仍缺，可以另立前瞻性固定阈值变体。例如在 HTRU2 全行训练侧用三个固定效用折和共同 L2 模型，穷举八列的全部子集，计算一次全局 Shapley 值，以 τ＝0、K＝5 限定候选，再按加入一列后的验证 F1 贪心扩展。同分按原列序，即使增益为负也继续，直到选满五列或用完合格候选。保留实际列数，零候选标为不可行并单列分母。空集效用用训练阳性率产生的常数预测。上述设定需另行冻结及计费，本方案的两臂预算未计入此变体。

## 配对设计与训练边界

沿用已审计 HTRU2 的 17,898 行、八个数值变量及外层折 0–4。执行前核对数据与划分 SHA-256、行号顺序及组隔离。历史划分用特征向量指纹标记组，当前均为单行组。各折外层训练行数为 14,318、14,318、14,319、14,319、14,318。完整测试行数依次为 3,580、3,580、3,579、3,579、3,580。

设当前训练分区共有 n 行，合计抽取 ceil(n/2) 行，在各类内按配额无放回抽取。用最大余数法分配类别配额，余数相同按类别编号，任一类分配不足两行则停。类内先按行 ID 排序。两臂最终训练行数依次为 7,159、7,159、7,160、7,160、7,159。每次在当层完成划分后才从训练部分抽半；验证折和测试折保留全部行。

| 分区 | 抽样或共用对象 | 可见数据与复核 |
|---|---|---|
| 外层训练 | 生成一份最终半样本，供 ASSS 冗余矩阵、L1 最终排名和两臂最终 L2 共用。 | 封存训练行 ID、类计数、实际行率、种子和哈希；两臂逐项相同。 |
| ASSS 效用 | 从完整外层训练池生成四个分层 80% 子池。每个子池先分三个效用折，各折只对训练部分抽半。 | 同一效用折的所有特征联盟使用同一行清单、验证行和模型种子。每个子池只覆盖自己的训练、验证数据。 |
| L1 调参 | 在完整外层训练池分三个选择内折。同一折的五个 C、L1 排名及其后的 L2 验证拟合共用该折训练半样本。 | 在完整内层验证折上算 F1；参数选定后，在共同外层半样本上重建排名。 |

同一训练分区只生成一份半样本。种子以新协议标识、根种子、外折、用途及排序后的分区行 ID 摘要派生，抽行坐标不含方法名或 C。拟议抽行根种子为 2026110309；其他分折、贡献、排列和模型种子沿用 A3 的角色坐标并在启动前锁定清单。审计跨方法检查相同分区，并分别记录 ASSS 特有的效用折与 L1 特有的调参折。

所有标准化参数仅从当前所选训练行与列估计。使用列均值和总体标准差，零标准差置 1；非有限输入停包。两臂最终均为带截距、无类权重的 L2 逻辑回归，C＝1，lbfgs，最多 5,000 次迭代，收敛容差 10⁻⁶。同折最终种子相同，概率 ≥ 0.5 判阳性。先封存两臂选列、超参数与行清单，才开放该折测试预测。

## 选列规则与训练预算

ASSS111 启用方差修正、贡献波动惩罚和冗余惩罚。每个子池用 M＝256 条均匀随机排列估计贡献，子集效用为三个完整效用验证折的等权阳性 F1。空集使用所选训练行的阳性率作常数概率。对四个子池的贡献取均值及样本方差，扣除平均蒙特卡洛方差后将负值截为零。得分取均值减去 0.5 倍修正标准差。每步再扣除 0.1/8 倍候选列与已选列的绝对 Spearman 相关之和，同分按原列序，取路径前四列。

L1 排名用 liblinear、有截距、无类权重，收敛设置同上。正则参数 C 依次为 0.01、0.1、1、10、100。每个内折按标准化后的绝对系数降序取四列，零系数和并列均按原列序处理；再用新的共同 L2 在同一训练半样本拟合，在完整验证折计分。三折等权平均 F1 最高的 C 胜出，同分取较小 C。两臂均保存有序路径或排名，最终拟合统一按原始列序。

| 未来操作（按尝试计数） | 分类器上限 | 编码器上限 |
|---|---:|---:|
| 单折主运行：4×3×255 个非空联盟，加 30 次 L1 调参与验证、1 次重排、2 次最终拟合 | 3,093 | 3,094 |
| 五折主运行合计 | 15,465 | 15,470 |
| 独立审计：每折 2 个最终模型及 4×3 个全联盟模型 | 70 | 70 |
| 折 0 冷重放：两臂完整重算一次 | 3,093 | 3,094 |
| 训练侧计时：折 0 最终半样本，全八列 L2 六次，五个 L1 参数各两次 | 16 | 16 |
| 包含探针的五折总上限 | 18,644 | 18,650 |

## 评价终点与逐折验收

主终点是同一测试折的阳性 F1 差 Δ＝F1(ASSS111) − F1(L1)。逐折列两臂分数及有符号差，再报五折等权平均与正、零、负折数。两臂面对完全相同的测试行，训练折彼此重叠，结果用于开发比较。模型表现持平或落后也可通过交付验收。

次要终点包括 ROC AUC、平均精确率（AP）、混淆计数、所选原始列、两臂集合交集及 Jaccard、k、实际行率与单元格保留率（实际行率 × 4/8）。如列出 0.01 损失线，比较对象是已验收的同折全行八列 F1，只在核对测试行身份后计算“全量 F1 − 本臂 F1”；分开报告每臂超线折。该线只作描述，不能用来更换方法、列数或阈值。

| 验收点 | 通过条件 |
|---|---|
| 开始首折前 | 锁定源码、环境、数据、划分、种子清单、不可变输入和 F 盘新运行路径；通过无拟合模拟的行隔离、配额、预算及中断测试。另行批准训练探针和逐折账户上限，核对入包读数，保留 23 个百分点。 |
| 工时与失败 | 探针只接触训练侧，按 L1/L2 调用次数作保守估时并计入预算。拟设单次调用 1 小时、单折包 2 小时、全包 12 小时警戒；超限停止新增单元。收敛警告、非有限值、行或哈希不符、账本中断均停止，保留记录，禁止静默重试。 |
| 每折交付 | 用已存行清单和种子核验抽样，用联盟效用、排列、系数及验证预测重建排名和选列。仅对两臂最终模型及 12 个全联盟模型直接重拟合，按保存概率重算指标。行、特征、次序及计数须一致；连续量拟按绝对误差 ≤10⁻¹²、相对容差 0 验收，执行前冻结。 |
| 五折签收 | 折 0 冷重放使用相同种子、全新进程和空缓存。全五折核对账本、十份主测试输出及直接审计。断点重启已完成单元须零新增操作；F 盘归档须通过 CRC、逐文件哈希和解压恢复。 |
