The snapshot contains resource arithmetic, identity binding, guarded accounting, adapters, training-side timing, independent audit logic and selected no-fit tests. Live authorizations, quota observations, execution launchers, data partitions, ledgers, run output and the complete original freeze dependencies are deliberately absent. This is an inspection package, not a portable execution bundle. Its files can refer to original paths and sibling resources; do not run them as a public quickstart or use public path-mapped JSON as replacement frozen inputs.

The published gate is historical evidence of a completed 75-task confirmation probe. It cannot authorize a new main run. The Adult main/replay/direct-audit scientific package has not run. Source tests were parsed for syntax during publication; they were not rerun here. The reported 136 no-fit tests and 11,544 independent checks refer to the accepted original preparation delivery.

Use the repository-root quickstart only for the earlier HTRU2 demonstration. Root scientific code and the October update are unchanged by this publication.
