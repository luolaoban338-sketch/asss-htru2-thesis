# A4 XOR Random Forest Method Validation

English research progress report | 26 October 2026 | A4 2b RF half

The authorized random forest half of the XOR package completed eight independent generated datasets and 48 nested selectors. For CSR 111 at the prespecified size two, mean joint recovery of both signal variables was 1.000000 and mean test F1 was 0.943483. The tables retain all prescribed variants and all eight datasets. The paired logistic regression layer remains pending, so this report completes only the RF half.

## Frozen design

Each dataset has six independent standard normal predictors, 600 training rows and 2000 independently generated test rows. The binary outcome is the XOR of the signs of X1 and X2, with independent label flips of probability 0.05. X3 through X6 are noise. Joint recovery is the indicator that a selected set contains both X1 and X2, averaged over nested resamples.

The fixed random forest uses 64 trees, maximum depth four, minimum leaf size five, all predictors eligible at each split, bootstrap sampling and one computational thread. No hyperparameter was retuned after observing XOR performance. Each of six selector resamples has 480 training rows; four contribution samples of 384 rows each use two utility folds. All final models use the same selector rows and probability threshold 0.5.

C denotes Monte Carlo variance correction, S the stability penalty and R the redundancy penalty. Selection uses B=4, M=64, lambda=0.5 and eta=0.1. All eight CSR variants, k=1/2/3, a random feature path and all six features remain recorded. Structural aliases 001=101 and 000=100 remain visible. Test data and exact diagnostics are accessed only after selection commitments are saved and hashed.

The full feature arm includes both signals by construction; its perfect joint recovery is not evidence that a selector identified the correct subset. Likewise, a fixed random feature path can have high conditional stability while omitting signal. The feature budget differs for the full feature arm, so it is context rather than an equal-size comparison.

The frozen protocol specifies joint signal recovery, test F1, AUC and balanced accuracy for XOR at k=2. It does not introduce a new learner-superiority test. The RF and LR layers share the intended data and partition coordinates, but the LR layer has not been completed in this delivery and no paired learner conclusion is drawn.

The complete source summary retains k=1 and k=3, every CSR arm, selected feature identities and full paths. Those secondary outputs were not used to select a more favorable main size, data seed or model setting. Weak-signal omission from the signal-noise scenario is not an XOR endpoint and remains undefined.

## Interpretation and remaining work

This is a descriptive synthetic diagnostic for one XOR generator, one fixed RF configuration and eight independent datasets. Null, mixed and adverse outcomes remain evidence. Results cannot establish overall superiority, cross-dataset robustness, noninferiority, deployment readiness or general scalability.
