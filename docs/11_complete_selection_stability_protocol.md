# 完整选择流程稳定性开发协议

2026-10-01，在HTRU2本轮首次拟合前固定。新 run ID：stability-htru2-pilot-20261001-v1。沿用 joint_pilot_v1 的 B=4、M=256、三内层折、三效用折、λ={0,0.5}、η={0,0.1}、k=1…8、四种采样条件及 ε=0.01，不根据外层结果改变搜索规则。

## 设计与边界

仅使用既有 HTRU2 第0外层折的训练池。加载数据后先建立只含该池的 Dataset，实验函数无法索引被排除的外层测试行。持久化原始位置和 row ID 的映射以及测试排除清单；排除检查只涉及标识和组，不评价测试特征或标签。

固定10次独立种子，分别在训练池内按类别配额无放回抽取80%行。行抽取允许保留某组的一部分，但每一层训练/验证都按组隔离。各比较条件共享相同重抽样和内层折。每次重新完成三折内层预算搜索、候选聚合、八种规则决策，并在整个重抽样上重建四个选择器，导出所选特征和行集合。B=4是每个选择器内部贡献重抽样次数，不能计为完整流程次数。

重抽样、内层划分、采样器和排列种子一起变化；测量的是固定开发池下数据扰动与算法随机性共同产生的稳定性。没有隔离单一噪声来源。各重抽样相互重叠，不能推广成10个独立数据集。此阶段以完成特征选择为终点，不拟合最终分类器，也不评价外层测试或重抽样未选行。

## 指标

令 Z 为10×8二元选择矩阵；特征频率为各列均值，方差使用 ddof=1。Nogueira 指标为 1−mean(column sample variance)/[q(1−q)]，q为平均保留变量比例。全选/全空时分母为零，记为null并标明原因；负值保留，不截断到0。来源：[Nogueira, Sechidis and Brown (2018), JMLR 18(174), Eq. 2](https://jmlr.org/papers/volume18/17-514/17-514.pdf)。

另报告所有45个无序对的 Jaccard=交集大小/并集大小及均值；空集与空集按本项目约定记1。报告每次特征数、方法、ρ、λ、η、k及实际单元比例。全量和仅采样条件恒定全选是退化参照，不能据此声称其具有有效特征筛选的稳定性优势。

仅作描述性比较，不给p值或置信区间，不将45对相似度当成45个独立重复。10次是预定最小开发验证规模，不能声称总体稳定性已充分估计，也不利用这些稳定性结果反向修改本轮协议。
