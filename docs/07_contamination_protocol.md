# 训练数值污染开发验证方案

制定与执行日期为2026年9月27日。本轮继承9月26日的基线实现与配置，以及原执行计划第5.2节规定的异常生成方式。昨天的开发基线已经可见；本轮是在污染拟合前固定的开发扩展，不是整个研究的预注册或最终确认性实验。

## 研究问题与运行矩阵

在固定逻辑回归、样本率和几何规则下，训练数值污染会怎样影响完整测试折上的F1与AUC？稳健几何50%相对普通几何50%和随机50%的变化是否一致？

HTRU2沿用本轮基线五折分组划分，比较全量、随机50%、普通几何50%、稳健几何50%。每折每种方法运行一次干净条件，以及5%和10%污染各三个预先固定的随机种子，共140次拟合。全部原始预测变量仍被保留。Adult官方测试分区不参与。

## 污染规则

每折只读取干净训练数据估计数值列四分位距，按非缺失观察值的线性分位数计算；零IQR列排除。用同一随机排列无放回抽取ceil(比例×训练行数)行，因此同一随机种子下5%行集合是10%的前缀。各行从有观测且IQR大于零的数值列均匀选一列，等概率选正负号，加上正负10倍IQR。单元格随机种子按行ID派生，各方法共享污染。若选中行没有合格数值单元格，该条件明确失败，不能偷偷换行。

标签、类别变量、组标识、审计字段和测试折均不修改。偏移不按业务边界截断，因此可能产生负计数等不具现实含义的数值；这是数值异常压力测试，不能解释为现实世界错误机制的精确模拟。污染事件保存在单独文件，只用于事后核验。

采样器几何预处理在受污染的完整训练折拟合；分类器预处理仅在受污染且被选中的训练行拟合。稳健截尾只应用于采样距离，分类器仍使用选中行的受扰动数值。本轮未搜索超参数，因此应表述为固定参数敏感性，不能写成已完成干净内层调参的正式嵌套污染实验。

## 统计口径

以同一数据集、折、方法的干净结果为参照，计算F1与AUC的配对差，正值表示污染后更高。先对每折三次污染取平均，再对五折等权平均；保留所有逐折逐随机种子结果。折间SD仅描述同一交叉验证划分下的波动。训练折相互重叠、三次污染共享干净参照，不能把15个数作为独立研究对象计算普通独立样本显著性。

污染点保留率是保留的污染行数除以该训练折污染行总数；所选行污染比例是保留污染行数除以实际所选行数。二者不能混用。全量方法保留率为1；保留率较低不自动意味着预测更好。未进行显著性检验、非劣效检验、阈值优化或基于结果的策略选择。

流水线时间包括采样、分类器预处理、拟合及预测，排除污染生成、载入、划分、核验及写盘；条件顺序固定，单次计时仅作描述。重复运行用于检查确定性，不作为新增独立实验或速度重复。

## 验收

逐个拟合检查训练测试组隔离、实际改动单元格、IQR偏移、嵌套污染集合、真实训练行和类别配额、污染保留分母、所选行预处理参数及保存系数重建的完整测试预测。20个干净拟合须与昨天的选择、系数和预测完全相同。HTRU2首折全条件共28次重跑应一致；断点续跑须跳过完成记录并保留原文件。
