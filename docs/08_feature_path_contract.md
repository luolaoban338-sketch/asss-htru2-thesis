# 特征路径首版操作定义

2026年9月27日补充。experiments/feature_path.py提供独立的最小实现，尚未接入真实数据的特征子集搜索或共同预算。该文件的“完成”只指通过解析例子检查，不能解释为完整ASSS验收。

关联矩阵只接受当前选择器训练分区中已选中的行。其调用方负责执行分区与选行检查，不应将整个训练及验证拼接后传入。数值缺失和类别缺失仅在这些行拟合填补规则，分类变量整体独热编码。每对编码列计算绝对Spearman相关，常量列关联为0；原始变量块间取最大值，原始变量自身对角线设0。

首版明确将每对原始变量只计一次：G(S)=Σ(j∈S)score_j−(η/d)Σ(i<j且i,j∈S)R_ij。这是为落实原方案所固定的代码级计数约定；如果后续核对原始排版公式使用双重计数，需要对η作一致换算，不能混用参数后称同一配置。

每步增加最大边际分数的变量，完全平局按原始变量顺序。即使边际分数为负也继续到全部变量，保留k=1…d的完整路径。η=0退化为稳定贡献分数的固定降序；全变量候选一定存在。此贪心路径不保证全局最优交互组合，原始变量块最大相关也不能识别所有非线性冗余。

四项解析检查覆盖相关副本、常量、类别块、零惩罚、负分数不停机、固定平局、手算目标值及非法关联矩阵。后续要在新的运行配置中固定η网格，明确调用方训练分区，并使用独立内层验证选择k与样本率。当前不能根据污染或外层分数选η。
