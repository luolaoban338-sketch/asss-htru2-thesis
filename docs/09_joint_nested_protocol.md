# 共同预算与三层验证开发协议

2026-09-28，首次联合运行前固定。HTRU2 已用于前期开发，本轮不是确认性主实验。旧运行不追加或覆盖。

## 固定设计

- 沿用基线的五个外层分组折；每个外层训练分区内创建三个分组内层折。每个内层训练分区独立重建特征流程，不复用昨天从更大训练池计算的贡献。
- 四种样本条件：全部行、分层随机50%、普通几何50%、稳健几何50%。每个分区和样本条件使用 B=4 个80%分层行重抽样；其内部使用三个分组效用折。重抽样本身可抽取组的一部分，但任何训练／验证边界均以组隔离。
- 本轮排列数固定 M=256，是根据昨天的训练侧误差诊断选择的开发预算，不声称充分。八变量全部子集也计算精确贡献，仅用于近似误差诊断，选择器仍使用排列估计与方差修正。
- λ∈{0,0.5}，η∈{0,0.1}，k=1…8；两个ρ为0.5和1。η=0作为无冗余惩罚对照。网格不会根据本轮外层分数调整。
- 当前训练分区选一次最终候选训练行，用这些行计算冗余矩阵，所有λ/η/k候选共享同一行集。各效用折仍另行在其训练侧选行，保持博弈固定。
- 分类器沿用锁定逻辑回归与0.5阈值。原始变量整体选择，模型列按原始字典排序，保证全变量候选与全量基线完全相同。

## 候选与决策

每折有4×2×2×8=128个参数候选；同一训练分区与采样条件下，相同原始变量子集只拟合一次，保留全部参数到模型的映射。内层模型在完整内层验证折评价，按三折等权平均F1判断。

门槛为同内层折的全行全变量基线平均F1减0.01。按以下顺序选择：平均实际行率×k/8最小、k最小、平均F1最大、固定候选编号最小。浮点比较分阶段使用1e-12；所有候选评价失败则停止并记录，不静默淘汰失败条件。

分别输出不选择、仅选样本、仅选特征、联合选择、顺序选择；另输出仅允许随机／普通／稳健采样与全量回退的联合候选对照。全量回退必须与基线相同且总是满足内层门槛。顺序方法先用全部变量选择采样条件，再仅在该条件下选择特征；两步共用原始全量门槛，不叠加容差。

本轮顺序／联合使用共同的完整已评价候选表，以比较决策规则；共享执行不是两个算法分别计时，也不是实际提前终止的顺序搜索成本实验。报告去重后的真实拟合数和完整共享搜索成本。

## 外层重拟合和核验

先保存只含内层分数的决策文件。随后在完整外层训练集重新计算被选采样条件的贡献与路径，用已选参数重新生成行列集合，再评价完整外层测试折。可以为开发审计生成四种条件的完整外层训练路径；额外工作必须计入实测成本。

保存数据、代码、环境、配置与折划分校验值；每个贡献博弈、分区选择器、候选评分和外层预测独立提交完成标记，支持中断恢复。审计逐层检查行与组隔离、配额、冗余与路径、门槛和决策、全量回退、预测及指标重建。重跑预定首折和首个内层分区的代表性工作，不因结果好坏挑选重跑。

报告五个外层折的原始值、描述性均值／标准差及合并折外预测。折间训练数据重叠，不开展独立样本显著性检验。内层可行不保证外层损失≤0.01，违反情况完整报告。正式10次完整流程稳定性、冻结参数后的污染重拟合、其他数据集和特征基线另行实施。
